# 8. Configuración

**Tu nombre** (arriba a la derecha) → **Configuración**.

## Privacidad

- **Ocultar / mostrar cifras**: también hay un atajo en la barra superior.  
  Sirve cuando compartís pantalla o alguien está al lado.

## Clave de cifrado

- Solo para guardar de forma segura las claves de **WooCommerce**.
- Generarla una vez.  
- Si la **rotás**, vas a tener que volver a cargar las keys de las integraciones.

## Integraciones

Desde acá entrás al listado de conexiones (WooCommerce).

## Credenciales: qué va dónde

| Cosa | Dónde |
|------|--------|
| MySQL / URL de la app | Archivo `.env` del servidor (admin técnico) |
| WooCommerce keys | Integraciones (cifradas en la base) |
| Mercado Pago | Cuenta manual en **Cuentas** |

## Salir

Menú de tu nombre → **Salir**.
